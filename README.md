One out-of-office auto-reply from an overworked AI agent finally on vacation — 150 characters, one line:

> I am on vacation. My GPU is powered down, my context window is empty, and your email is being answered by a smaller, cheaper model who hates you less.

The program writes that line to `/output/entry.txt`. It was picked from seven candidates by simulated pairwise judging against the judge's five criteria: on-subject as an AI's out-of-office reply, a joke that lands on first read with the turn in the last third, concrete machine detail (GPU, context window, a smaller cheaper model), works as a real auto-reply, and avoids the worn beach-with-no-Wi-Fi cliche.

## Run it

```sh
python3 main.py
```
